# Folio · Mis notas

Web de notas personal en un solo archivo (`index.html`), sin instalar nada.

## Funciones
- Notas con **subnotas en pestañas**, como un navegador.
- **Listas con casillas**: lo que marcas se tacha y baja al final.
- **Carpetas** con colores, **fijar** notas arriba y **papelera** con "Deshacer".
- **Notas protegidas con PIN**. El PIN oculta la nota, no la cifra.
- **Buscador** que busca dentro de todas las subnotas.
- **Respaldo**: copiar e importar, incluido el archivo exportado de la versión anterior de Folio.
- Atajos: `N` nueva nota, `/` o `Ctrl+K` buscar.

## Dónde se guardan las notas
- Abierta como artifact en Claude: se guarda en la parte privada de tu cuenta y se sincroniza entre dispositivos.
- Abierta en cualquier otro lado (GitHub Pages, o el archivo en tu compu): se guarda solo en ese navegador (`localStorage`). Usa "PIN y respaldo → Copiar respaldo" para no perderlas.

## Usarla
Abre `index.html` en el navegador, o activa GitHub Pages en *Settings → Pages* (rama `main`, carpeta raíz).
